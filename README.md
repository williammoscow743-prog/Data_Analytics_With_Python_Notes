# Data Analytics with Python — Course Notes

Personal study notes from a **Data Analytics with Python** course, covering databases, SQL, Python fundamentals, pandas, business analytics, data visualization, and an introduction to machine learning / AI concepts (RAG, vector embeddings).

These notes were originally handwritten and have been transcribed and organized here as part of a course assignment.

## 📚 Contents

| # | File | Topics Covered |
|---|---|---|
| 1 | [Data & Databases](notes/01-data-and-databases.md) | Structured vs. unstructured data, relational databases, DBMS, data warehouses, OLTP vs. OLAP, schemas, fact & dimension tables, primary/foreign keys |
| 2 | [SQL Fundamentals](notes/02-sql-fundamentals.md) | SQL basics, arithmetic/comparison/logical operators, aliases |
| 3 | [Python Fundamentals](notes/03-python-fundamentals.md) | Variables, naming conventions, data types, strings, lists, tuples, dictionaries, conditionals, loops (`for`, `while`, `zip`, `enumerate`) |
| 4 | [Pandas & Data Analysis](notes/04-pandas-data-analysis.md) | Pandas basics, DataFrames, reading CSVs, `groupby`, feature engineering, EDA workflow, pivot tables, Databricks/Colab workflow |
| 5 | [Business Analytics](notes/05-business-analytics.md) | Business models, KPIs, CSAT, cost/profit/revenue formulas, campaign planning, post-implementation reviews (PIR) |
| 6 | [Data Visualization](notes/06-data-visualization.md) | Choosing the right chart (bar, line, pie/donut), metrics vs. categorical data, translating business asks into data-driven questions |
| 7 | [Machine Learning & AI](notes/07-machine-learning-and-ai.md) | ML process (data collection → EDA → feature engineering → train/test split → model selection), supervised vs. unsupervised learning, RAG, vector embeddings |
