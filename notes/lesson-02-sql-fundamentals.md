# SQL & Data Processing Fundamentals

## SQL (Structured Query Language)
- Structured — used to interact with structured data.
- Query — to retrieve data.

```
Data Warehouse (Big Data)  <---->  SQL (Structured Query Language)
```

The SQL layer is used for:
- Data cleaning
- Data exploration
- Data processing
- Data wrangling

## Operations

1. **Arithmetic Operations** — `+`, `-`, `÷`, `×`
2. **Comparison Operations** — `=`, `<`, `<=`, `>=`, `>`
3. **Logical Operators** — `AND`, `BETWEEN`, `IN`, `NOT`, `OR`

## Aliases
- A function used to rename something, e.g. `AS` for a nickname/alternative column name.
